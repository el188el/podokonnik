# Подоконник 🌱

Уютная игра про комнатные растения: Telegram Mini App и веб-версия (PWA).
Поливай, переставляй к свету, бери черенки, дари их друзьям и собирай гербарий.

Объединяет две концепции: Gemini (прогрессия, магазин, сезоны, декор, соцмеханики)
и Grok (свет и стороны окна, честный уход, подарки черенков по ссылке).
Полный план — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Что уже есть

- **18 популярных в России растений** в трёх уровнях сложности: от хлорофитума и
  «щучьего хвоста» до фиалки, декабриста и орхидеи. Новые виды открываются по уровням.
- **Честная симуляция в реальном времени** (и когда игра закрыта): влажность, свет по
  стороне окна и зоне («у стекла» / «в глубине»), здоровье, перелив, засуха, зима.
- **5 стадий**: черенок в стакане → корни → росток → молодое → взрослое. Первый
  черенок и подарки укореняются за 2 минуты.
- **Уход**: полив (и перелив, если настаивать), опрыскивание, подкормка, пересадка
  в большой горшок, перестановка перетаскиванием.
- **Цветение и сезоны**: герань цветёт летом, каланхоэ — зимой, а декабрист — только
  после осеннего «зимнего покоя».
- **Прогрессия**: опыт и уровни, валюта «листики», 23 достижения, ежедневные задания,
  серия заходов с наградами.
- **Магазин**: черенки, горшки (гжель, хохлома, эмалированная кружка…), декор
  (кот, радио, тюль, фитолампа, гирлянда), набор «Бабушкин подоконник», новые подоконники.
- **Подарки черенков** по ссылке (в Telegram — прямо в мини-апп), «Сказать спасибо» и
  «Показать, как подросло 📸».
- **Соседка польёт** на время отпуска, экран «Пока тебя не было», гербарий с уходом
  «по-настоящему» (цены в рублях, как укоренить бесплатно).
- Сохранения: localStorage + облако Telegram (CloudStorage). Прогресс первой версии
  игры переносится автоматически.

## Разработка

```bash
npm install
npm run dev          # http://localhost:5173/?debug — с панелью перемотки времени
npm test             # тесты движка симуляции
npm run build        # сборка в dist/
npm run gen:assets   # перегенерировать страницы подарков и картинки превью
```

Стек: React 19 + TypeScript + Vite, framer-motion, zustand, vite-plugin-pwa.
Графика растений процедурная (`src/ui/art/PlantArt.tsx`), без картинок.

```
src/game/      логика: виды, симуляция, прогрессия, задания, магазин, сохранения
src/platform/  Telegram / веб / Discord / нативное приложение — одна прослойка
src/ui/        интерфейс: подоконник, карточки, вкладки, графика
scripts/       генерация страниц подарков и OG-картинок
```

## Публикация

Сайт собирается и выкладывается на GitHub Pages автоматически при пуше в `main`
(`.github/workflows/deploy.yml`). Один раз в настройках репозитория:
**Settings → Pages → Source: GitHub Actions**.

## Подключить к Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` → имя и юзернейм бота.
2. Там же `/newapp` → выбрать бота → указать URL `https://el188el.github.io/podokonnik/`
   и короткое имя приложения (например, `game`).
3. В репозитории: **Settings → Secrets and variables → Actions → Variables** добавить
   `VITE_TG_BOT` (юзернейм бота без @) и `VITE_TG_APP` (короткое имя из шага 2).
4. Перезапустить сборку (Actions → «Сборка и публикация» → Run workflow).

После этого ссылки на подарки открываются прямо в Telegram: `t.me/<бот>/<app>?startapp=…`.

## Сервер (Supabase) и бот

Сервер даёт: вход через Telegram, общий прогресс на всех устройствах, серверное время
(перевод часов на телефоне не ускоряет рост), подарки «одна ссылка — один получатель»
на всех устройствах, приглашения друзей с наградой и напоминания от бота.
Без сервера игра тоже работает — просто офлайн.

Всё разворачивается само через GitHub Actions. Нужно один раз заполнить
**Settings → Secrets and variables → Actions**:

| Где | Имя | Откуда взять |
|---|---|---|
| Variables | `SUPABASE_PROJECT_REF` | Supabase → Project Settings → General → **Project ID** (≈20 латинских букв) |
| Secrets | `SUPABASE_ACCESS_TOKEN` | supabase.com → аватар → **Account preferences → Access Tokens → Generate new token** |
| Secrets | `SUPABASE_DB_PASSWORD` | пароль базы, который задавали при создании проекта (сбросить: Project Settings → Database) |
| Secrets | `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| Variables | `VITE_TG_BOT`, `VITE_TG_APP` | имя бота без @ и короткое имя мини-аппа |

Потом: **Actions → «Сервер (Supabase и бот)» → Run workflow**, а затем
**«Сборка и публикация» → Run workflow**. Первый создаст таблицы, загрузит функции и
подключит бота (вебхук, команды, кнопка «🪴 Играть»), второй пересоберёт сайт уже с сервером.
Напоминания запускаются сами каждые полчаса планировщиком внутри Supabase (pg_cron) — минуты GitHub Actions на них не тратятся.

Секреты нигде, кроме GitHub Secrets, не хранятся: остальные ключи сервер выводит из токена бота.

Необязательно: переменная `TG_ADMIN_ID` (твой числовой id в Telegram, узнать — у @userinfobot).

Необязательно: канал игры. Создай публичный канал в Telegram, добавь бота туда администратором и задай переменную
`VITE_TG_CHANNEL` (имя канала без @). Бот будет каждый день в 10:00 по Москве публиковать «совет дня», а по понедельникам —
итоги конкурса «Подоконник недели». В игре появится кнопка канала.
Тогда сообщения игроков из `/paysupport` будут приходить тебе в личку от бота.

### Тестовый режим: все привилегии

Supabase → **SQL Editor** → вставить содержимое [`docs/tester.sql`](docs/tester.sql) → **Run**,
потом открыть игру в Telegram. Выдаётся «Садовник+» на год, 5000 🍃, 12 уровень, весь декор,
кухня и балкон, все редкие формы и платная ветка текущего ивента.

### Покупки за Telegram Stars

Отдельно подключать ничего не нужно: звёзды работают через бота. Товары и цены — в
`src/game/products.ts` (подписка «Садовник+» 99 ⭐/мес, редкие формы 50–75 ⭐, пакеты листиков).
Покупка выдаётся сервером только после `successful_payment` от Telegram; повторная доставка
платежа ничего не выдаёт дважды. Звёзды выводятся через @BotFather → бот → Payments / Fragment.

```
supabase/migrations/   таблицы: игроки, сохранения, подарки, входящие награды
supabase/functions/    api (вход, синхронизация, подарки), bot (вебхук), notify (напоминания)
supabase/tests/        тесты: подпись Telegram, токены, напоминания (deno test supabase/tests)
```
Логика растений общая с игрой: `npm run sync:shared` копирует её в `supabase/functions/_shared/game`.

## Реклама за награду (Adsgram)

1. Зарегистрируйся на [adsgram.ai](https://adsgram.ai), добавь платформу Telegram Mini App (бот),
   создай блок **Rewarded video**.
2. GitHub → Settings → Secrets and variables → Actions → **Variables**: `VITE_ADSGRAM_BLOCK` = номер блока.
3. Перезапусти «Сборка и публикация».

Появится «🎬 Ролик за награду» в магазине (+20 🍃, до 5 в день) и «Ролик — и корни сразу» у черенка.

## Аналитика

Игра отправляет на сервер короткие события (вход, вкладки, покупки, подарки, ивенты) —
без личных данных. Сводка: напиши боту **/stats** (работает только для `TG_ADMIN_ID`):
игроки, новые, DAU/WAU/MAU, удержание D1/D7, звёзды за 7 и 30 дней, платформы, топ событий.
Сырые данные — таблица `analytics_events` в Supabase.

## Discord Activity

1. [discord.com/developers](https://discord.com/developers/applications) → New Application.
2. **OAuth2**: скопируй Client ID и Client Secret; добавь Redirect `https://127.0.0.1`.
3. **Activities → URL Mappings**:
   - `/` → `el188el.github.io/podokonnik`
   - `/sb` → `<SUPABASE_PROJECT_REF>.supabase.co/functions/v1`
4. **Activities → Settings**: включи Activities.
5. GitHub → Variables: `VITE_DISCORD_CLIENT_ID`; Secrets: `DISCORD_CLIENT_SECRET`.
6. Перезапусти «Сервер (Supabase и бот)» и «Сборка и публикация».

В Discord игра открывается в голосовом канале, вход — по аккаунту Discord, «Пригласить друга» —
окно приглашения Discord. Покупки за звёзды там недоступны.
